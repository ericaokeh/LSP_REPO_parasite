Honestly, my view on using AI for programming has changed a lot this semester. At first, I kind of just saw it as a quick way to get answers when I was stuck on a bug, but now I see it more as a tool for getting through the boring stuff. For example, when I was working on my personal projects, I realized that instead of spending hours writing out the basic CRUD operations or setting up the initial boilerplate for my React components, I could use AI to generate the skeleton and then focus my energy on the actual peer-matching logic and how the data flows from Google BigQuery. Since I’ve worked on actual AI logic before at my internship, I know it’s not perfect and it makes mistakes, so I don't just copy-paste whatever it says. It’s been really helpful for handling the repetitive stuff in SQL too, like writing out long JOIN statements or formatting data, which usually takes up way too much of my time. It hasn't made coding "easier" in a lazy way, but it lets me spend more energy on the actual system design and the machine learning lifecycle instead of stressing over a missed semicolon or basic syntax.

For my future coursework and projects, I’m definitely going to keep using AI for fast prototyping. If I’m starting a new project or a complex lab, I like using it to brainstorm different ways to structure my code—like asking it to show me the pros and cons of using a specific design pattern versus another before I even open Figma to start the UI. I'm going to use it like a pair programmer that's always available, mostly to help me write unit tests that cover weird edge cases I might have missed during a late-night coding session. Another big thing is using it to explain weird, outdated documentation; if I’m working with a new API that has a 50-page manual, I’ll have the AI summarize the authentication flow so I can get to the actual implementation faster. I still plan on double-checking every single line it gives me though, because I've seen firsthand how "hallucinations" can break a project. My goal is to stay the one in control of the logic while using the AI to speed up the tedious parts of the development cycle.
