**Class: Aircraft
**
**Responsibilities
**
Maintain aircraft identification, type, altitude, and flight status data

Provide current flight data to the Transponder for transmission

Update internal state based on flight system inputs

**Collaborators**

Transponder

**Assumptions**

None

**Class: Transponder
**
**Responsibilities
**
Receive current flight data from Aircraft

Format flight data into the required high-density packet structure

Broadcast high-density data packets to the GroundStation

**Collaborators
**
Aircraft

GroundStation

Assumptions

**None**

**Class: GroundStation
**
**Responsibilities
**
Receive high-density packets from aircraft transponders

Decode and unpack received packet data into aircraft information

Process decoded data for storage

Update AircraftDatabase with the latest aircraft information

**Collaborators**

Transponder

AircraftDatabase

**Assumptions
**
None

**Class: AircraftDatabase
**
**Responsibilities
**
Store aircraft identification, type, altitude, and flight status information

Update aircraft records with new data received from the GroundStation

Provide aircraft data to other system components on request

**Collaborators
**
GroundStation

GraphicsDisplay

ControllerInterface

SystemAnalyzer

**Assumptions**

None

**Class: SystemAnalyzer
**
**Responsibilities
**
Retrieve aircraft data from AircraftDatabase

Analyze aircraft information to detect dangerous situations

Flag conflicts or hazards for GraphicsDisplay to alert the controller

**Collaborators**

AircraftDatabase

GraphicsDisplay

**Assumptions**

None

**Class: GraphicsDisplay
**
**Responsibilities
**
Retrieve updated aircraft data from AircraftDatabase

Render aircraft positions and flight information visually for the controller

Refresh the visual display every 10 seconds

Display safety alerts generated by SystemAnalyzer

**Collaborators**

AircraftDatabase

SystemAnalyzer

**Assumptions**

None

**Class: ControllerInterface
**
**Responsibilities**

Capture controller selections and input

Execute queries to retrieve detailed aircraft information

Present requested aircraft data to the human controller in a readable format

**Collaborators**

AircraftDatabase

GraphicsDisplay

**Assumptions**

None
